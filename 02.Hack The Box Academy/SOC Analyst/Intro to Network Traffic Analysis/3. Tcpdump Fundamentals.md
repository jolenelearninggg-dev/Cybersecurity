## Tcpdump 指令簡介

### 1. 驗證安裝

確認 Tcpdump 是否已安裝在機器上：

`which tcpdump`

<br>

### 2. 開始封包擷取

- #### Step 1：列出可用的網路介面

  `tcpdump -D`

  > 此指令會列出所有可擷取流量的網路介面及其編號。

- #### Step 2：選擇介面並開始擷取

  `tcpdump -i [介面名稱 or 編號]`

  > 將 `[介面名稱 or 編號]` 替換為 Step 1 列出的介面，例如：`eth0` 或 `1`。

<br>

### 3. 使用基本擷取過濾器
透過加入冗長度（verbosity）並以 ASCII 和 Hex 格式顯示封包內容：
`bashtcpdump -i [介面名稱 or 編號] -vX`

> `-v`：增加輸出的詳細程度；`-X`：同時以 Hex 和 ASCII 顯示封包內容。

完成後可以嘗試其他進階挑戰：

 - 關閉名稱解析（`-n`）
 - 顯示相對序列號（`-S`）

<br>

### 4. 將擷取結果儲存為 .PCAP 檔案
擷取網路流量並儲存至 PCAP 檔案，作為企業網路的基準範例：
`bashtcpdump -i [介面名稱 or 編號] -nvw [/儲存路徑/檔案名稱.pcap]`

> `-n`：關閉名稱解析；`-v`：增加詳細程度；`-w`：將結果寫入指定的 PCAP 檔案。

<br>

### 5. 從 .PCAP 檔案讀取擷取內容
將 PCAP 檔案讀入 tcpdump，並以絕對序列號 + Hex/ASCII 格式檢視：
`bashtcpdump -nnSXr [檔案路徑/讀取檔案.pcap]`

> `-nn`：關閉主機名稱與埠號解析；`-S`：顯示絕對 TCP 序列號；`-X`：以 Hex 和 ASCII 顯示內容；`-r`：從 PCAP 檔案讀取。


### 6. 封包過濾（Packet Filtering）
透過過濾器可以精準篩選想要的流量，減少雜訊、降低儲存空間需求，也讓緩衝處理更快速。
常用過濾器速查表
|過濾器|說明|
|------|---|
|`host`|雙向過濾，顯示與指定主機有關的所有流量|
|`src` / `dst`|指定來源或目的地的主機、埠號|
|`net`|過濾特定網段的流量，使用 `/` 斜線表示法|
|`proto`|過濾特定協定（如 ether、TCP、UDP、ICMP）|
|`port`|雙向過濾，顯示含有指定埠號的所有流量|
|`portrange`|過濾一段埠號範圍，例如 `0-1024`|
|`less` / `greater`|過濾小於或大於指定大小（bytes）的封包|
|`and` / `&&`|同時符合兩個條件|
|`or / ||`|符合其中一個條件即可|
|`not / !`|排除符合條件的流量|

host — 主機過濾
`bashsudo tcpdump -i eth0 host 172.16.146.2`
> 雙向過濾，來源或目的地符合指定 IP 的封包都會被擷取。
---

src / dst — 來源 / 目的地過濾
```
# 只看從此主機送出的流量
sudo tcpdump -i eth0 src host 172.16.146.2

# 搭配埠號使用
sudo tcpdump -i eth0 tcp src port 80
```

> src 只看送出方向；dst 只看接收方向，也可搭配 host、net、port 使用。
---

net — 網段過濾
`sudo tcpdump -i eth0 dest net 172.16.146.0/24`

> 過濾目的地為指定網段的流量，使用 CIDR / 表示法。
---

proto — 協定過濾
```
# 用協定名稱
sudo tcpdump -i eth0 udp

# 用協定編號（等效）
sudo tcpdump -i eth0 proto 17
```

> 常見對應：TCP=6、UDP=17、ICMP=1。
---

port / portrange — 埠號過濾
```# 單一埠號
sudo tcpdump -i eth0 tcp port 443

# 埠號範圍
sudo tcpdump -i eth0 portrange 0-1024
```
> port 是雙向的。若要確保只看 HTTP 流量，用 tcp port 80 比單純 port 80 更精確。
---

less / greater — 封包大小過濾
```
# 小於 64 bytes（常見於 SYN、FIN、KeepAlive）
sudo tcpdump -i eth0 less 64

# 大於 500 bytes（適合尋找檔案傳輸）
sudo tcpdump -i eth0 greater 500
```
---
and / or / not — 邏輯組合
```
# AND：同時符合兩個條件
sudo tcpdump -i eth0 host 192.168.0.1 and port 23

# OR：符合任一條件
sudo tcpdump -r sus.pcap icmp or host 172.16.146.1

# NOT：排除指定流量
sudo tcpdump -r sus.pcap not icmp
```

### 7. 進階技巧
輸出格式調整
|Switch|說明|
|`-S`|顯示絕對序列號（預設為相對序列號）|
|----|-------------------------------|
|`-v` / `-vv`|增加輸出詳細程度|
|`-X`|以 Hex + ASCII 顯示封包內容|
|`-A`|只顯示 ASCII 內容（不含 Hex）|
|`-e`|顯示 Ethernet header 資訊|
|`-l`|行緩衝模式，可即時 pipe 給其他工具|
|`-c`限制擷取封包數量|
|`-q`|簡化輸出資訊|

搭配 grep 使用
`sudo tcpdump -Ar http.cap -l | grep 'mailto:*'`

> -l 啟用行緩衝，讓輸出可即時 pipe 給 grep，快速搜尋關鍵字。

只看特定 TCP Flag（進階）
```
# 只顯示帶有 SYN flag 的封包
tcpdump -i eth0 'tcp[13] &2 != 0'
```

> 計算到 TCP header 第 13 個 byte，檢查第 2 個 bit 是否為 1（SYN flag）。
