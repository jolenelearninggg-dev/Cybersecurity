# Splunk 實戰篇
## 一、 核心獵捕邏輯：如何從 50 萬筆資料抓鬼？
1.由大到小（Aggregation）：先用 | stats count by sourcetype 看有哪些證據。

2.異常統計（Rare Analysis）：在資安界，「次數最少的通常最危險」。

3.欄位對齊（Field Mapping）：如果 App 沒畫面，先檢查 Computer 是不是該改成 ComputerName。

4.效能優化（Efficiency）：盡量使用 欄位名="值"（如 User="waldo"），避免全域關鍵字搜尋，否則 Splunk 會跑不動。

## 二、 必背的「邪惡」EventCode (Sysmon & Windows)
當你在 Splunk 看到這些代碼，請依照以下邏輯思考：
|EventID|類型|獵捕重點|
|---|---|---|
|1|Process Creation|父子關係異常。例如：`notepad.exe` 啟動了`powershell.exe`。|
|3|Network Connection|程式連向外部 IP 或非標準埠（如 8080, 4444）。|
|8|CreateRemoteThread|代碼注入。一個程式試圖把程式碼打進另一個程式（如注入`lsass.exe`）。|
|10|ProcessAccess|偷密碼（Credential Dumping）。重點看`TargetImage=lsass.exe`。|
|11|FileCreate|在`Temp`或`Appdata`資料夾下產生`.exe`或`.ps1`。|
|17/18|Pipe Created|工具間的溝通。常與`PsExec`或`Cobalt Strike`有關。|
|25|ProcessTampering|程序篡改。這是極高風險的訊號，通常直接就是惡意行為。|
|4662|AD Object Access|DCSync 攻擊。看到非機器帳號請求`0x100`權限。|

## 三、 常見惡意工具名稱
這些檔案出現在伺服器上，通常代表駭客已經進場了：
- `PsExec.exe` / `PsExec64.exe`：用來在內網「橫向移動」執行指令。
- `SharpHound.exe`：用來掃描 AD 網域所有權限弱點（BloodHound 的採集器）。
- `Mimikatz.exe`：最出名的偷密碼工具（雖然駭客常改名，但行為不變）。
- `Invoke-DCSync.ps1`：用來偽裝成網域控制站並偷走所有人的密碼。
- `comsvcs.dll`：常被用來搭配 rundll32.exe 傾印 LSASS 記憶體以獲取憑證。

## 四、 進階鑑識技巧：記憶體注入分析
在 EventCode=10（程序存取）中，如果看到 CallTrace 包含 UNKNOWN：
- 代表意義：這段指令不是從硬碟檔案發出的，而是從記憶體中的非法區域發出的（Shellcode）。
- 排除噪音：
  - 排除 .NET 相關（ni.dll, clr.dll）。
  - 排除 wow64（32/64位元轉換）。
  - 排除「自己動自己」（SourceImage != TargetImage）。
- 結論：排除完後剩下的 UNKNOWN，極大機率就是駭客的惡意注入。


## 五、 關鍵術語：
- IOC (Indicator of Compromise)：威脅指標。如惡意 IP (10.0.0.229) 或 檔案 Hash。
- False Positive (FP)：誤報。看起來像攻擊但其實是正常的系統行為（如 .NET 的 JIT）。
- Lateral Movement：橫向移動。駭客在公司內網從 A 電腦跳到 B 電腦。
- Credential Dumping：憑證傾印。從記憶體（LSASS）偷取密碼。
