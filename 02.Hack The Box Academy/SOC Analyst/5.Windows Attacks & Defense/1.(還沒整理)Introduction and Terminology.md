第一頁：AD 核心概念與防禦思維
主題：為什麼我們要像黑客一樣思考？

1. Active Directory (AD) 基礎結構
Organizational Units (OU)：組織單位，像資料夾，用來分類使用者與電腦。

Domain (網域)：共享同一個身分驗證資料庫（ntds.dit）的邊界。

Tree & Forest (樹與林)：多個網域組成的層級結構。Forest 是最終的資安邊界，一旦 Enterprise Admin 被控，整個集團就淪陷。

Domain Controller (DC)：網域控制站，AD 的大腦，負責所有人的登入驗證（KDC 服務）。

2. 核心協議：Kerberos
運作邏輯：它是一個「票據」系統。

AS-REQ / AS-REP：登入時向 DC 申請第一張大門票（TGT）。

TGS-REQ / TGS-REP：拿著大門票去換特定服務（如檔案伺服器）的入場券（TGS）。

關鍵術語：

SPN (Service Principal Name)：服務的身分證，用來告訴 Kerberos 這個服務是誰在跑。

KRBTGT：AD 裡最強大的帳號，負責簽署所有票據。

3. 為什麼從攻擊角度學習防禦？
防禦盲點：如果你不知道 0x17 (RC4) 加密代表什麼，你看到日誌顯示「Audit Success」會以為一切正常。

行為獵捕：了解攻擊者的「動作」（如：請求大量 TGS 票據），才能在數萬筆日誌中寫出正確的警報規則。

📄 第二頁：實驗室架構與工具箱
主題：工欲善其事，必先利其器

1. 實驗室角色分布
Attack Host (Kali Linux)：模擬外部黑客，擁有強大的運算力（Hashcat/John）來破解密碼。

Target Machine (WS001/Windows)：已被初步入侵的電腦，作為跳板去偵查網域。

Domain Controller (DC1)：紀錄所有罪證的地方。我們連到這台是為了「從管理員視角」看 Event Log。

2. 指令清單與技巧
遠端連線 (RDP)：xfreerdp /v:IP /u:user /p:pass /drive:share,.（關鍵： /drive:share,. 是為了讓 Linux 跟 Windows 能互傳檔案）。

檔案傳輸 (SMB)：smbclient \\\\IP\\Share -U user%pass。

get 檔名：把東西從受害者電腦抓回 Linux 破解。

字典準備：sudo tar -xvf /path/to/rockyou.txt.tar.gz -C /target/path/（備註： Linux 環境中路徑必須絕對精確）。

📄 第三頁：實戰案例 A — Kerberoasting
主題：針對「服務帳號」的密碼竊取

1. 攻擊原理
攻擊者利用「任何網域使用者都能申請服務票據 (TGS)」的特性。DC 會用該服務帳號的密碼 Hash 來加密票據，攻擊者拿到後帶回家進行「離線爆破」。

2. 關鍵指令
提取 Hash (Windows)：
.\Rubeus.exe kerberoast /outfile:spn.txt

破解 Hash (Linux)：
sudo hashcat -m 13100 -a 0 spn.txt rockyou.txt

3. 鑑識重點 (Blue Team)
Event ID：4769 (A service ticket was requested)。

異常行為：單一帳號短時間內請求大量不同服務的票據。

📄 第四頁：實戰案例 B — AS-REProasting
主題：針對「配置錯誤帳號」的密碼竊取

1. 攻擊原理
當帳號被設定為 「Do not require Kerberos preauthentication」 時，DC 不要求輸入密碼就會直接發回加密的 AS-REP 包。這通常是為了相容老舊設備，但會導致密碼直接暴露在爆破風險中。

2. 關鍵指令
提取 Hash (Windows)：
.\Rubeus.exe asreproast /outfile:asrep.txt

手動修正：必須在 $krb5asrep$ 後加上 23$ 告訴工具這是 RC4 加密。

破解 Hash (Linux)：
sudo hashcat -m 18200 -a 0 asrep.txt rockyou.txt

3. 鑑識與防禦
Event ID：4768 (TGT was requested)。

關鍵欄位：Pre-Authentication Type: 0（最明確的證據）。

防禦陷阱：設置 Honeypot User（如 svc-iam），專門用來誘捕掃描此漏洞的黑客。

SID 知識：調查時認 TargetSid 不認名稱，因為 SID 是唯一且不可變的。
