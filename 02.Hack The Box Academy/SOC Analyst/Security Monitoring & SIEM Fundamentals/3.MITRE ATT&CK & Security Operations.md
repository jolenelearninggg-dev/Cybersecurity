## 什麼是 MITRE ATT&CK？

Adversarial Tactics, Techniques, and Common Knowledge（對手戰術、技術與通用知識庫）。 <br>
這是一個由 MITRE 公司維護、全球公認的駭客行為百科全書。

它把駭客的行為拆解成三個層次（簡稱 TTPs）：
1. Tactics (戰術)：駭客的「目標」是什麼？（例如：他想進入系統、他想偷資料）。
2. Techniques (技術)：他用什麼「手段」達成目標？（例如：他透過發送釣魚郵件來進入系統）。
3. Procedures (程序)：具體的「執行細節」是什麼？（例如：他具體用了哪種惡意程式、怎麼寫腳本的）。

### SOC (資安中心)
1. 偵測與防禦缺口分析 (Gap Analysis)
   - 怎麼用？ 把這張大表格印出來，勾選你的公司目前能抓到哪些技術。
   - 目的：如果你發現「憑證竊取」這一行完全沒勾，那就代表這是你公司的防禦漏洞，你得趕快買工具或寫規則來補強。

2. 威脅情報共通語言 (Common Language)
   - 怎麼用？ 當大家都在用同一個標準說話。
   - 目的：以前分析師會說「有個壞人用很怪的方式進來」，現在我們會說「偵測到 T1566 (釣魚)」。這讓內部溝通和跨公司合作變得很精準。

3. 紅藍軍對抗 (Red Teaming)
   - 怎麼用？ 讓紅軍（模擬駭客）依照表格上的技術去攻擊公司。
   - 目的：測試藍軍（防禦者）到底能不能在 Wireshark 或 SIEM 裡抓到這些行為。

4. 行為分析 (Behavioral Analytics)
   - 怎麼用？ 不再只是找「病毒檔案」，而是找「駭客的行為」。
   - 目的：駭客會換病毒檔案，但 **行為（技術）** 很難改。例如：不管他用什麼病毒，只要他想「橫向移動」，動作就那幾種。我們針對「動作」下警報，抓得更準。
