# 網路威脅情資 (Cyber Threat Intelligence, CTI)
## 1. 威脅情資 (CTI) 的四大核心原則
不是所有的資料都能叫「情資」。一份好的情資必須具備這四個特質：
- 相關性 (Relevance)： 這情報跟「我」有關嗎？如果某漏洞只存在於 Linux，而你全公司都用 Windows，那這情報對你來說優先級就很低。
- 及時性 (Timeliness)： 情報是有時效性的。三年前的惡意 IP 現在可能已經變成合法的網站了。
- 準確性 (Accuracy)： 情報必須經過驗證。錯誤的情報會導致資安人員浪費時間去追查不存在的威脅。
- 可行動性 (Actionability)： 最重要的一點！看完情報後，你要知道**「下一步該做什麼」**（例如：封鎖某個 IP、更新某個補丁）。

## 2. 威脅情資 vs. 威脅獵捕
這兩者經常被搞混，但它們是互補關係：
- 威脅情資 (預測性)： 它是「外向」的。研究外面的駭客是誰、他們想幹嘛。目的是預測攻擊。
- 威脅獵捕 (實作性)： 它是「內向」的。根據情資給的線索，去自家的網路裡找人。

  例子： 情資告訴你「最近有一群賊專偷珠寶店（預測）」，獵捕就是「既然我們是珠寶店，我們趕快去檢查後門有沒有被撬開過的痕跡（行動）」。

## 3. 情資的三個層級
課程用了一個文氏圖（Venn Diagram）來表示，這三個層級服務於公司不同的部門：
- 戰略情資 (Strategic)： 給大老闆 (C-suite) 看的。
  - 內容： 高層級的趨勢、政治動機、誰在攻擊我們這個產業。
  - 目的： 決定年度預算要投在哪，或者公司政策要怎麼改。
- 戰術情資 (Operational)： 給中階主管/組長看的。
  - 內容： 駭客近期的「攻擊活動 (Campaign)」，他們用了哪些手法 (TTPs)。
  - 目的： 了解敵人的作戰方式。
- 技術情資 (Tactical)： 給第一線人員 (SOC/獵人) 看的。
  - 內容： 具體的技術指標 (IOCs)，如 IP、Hash 值、惡意網址。
  - 目的： 直接輸入到防火牆或 EDR 裡進行自動化防禦。

## 4. 如何解讀一份「技術情資報告」？ (以 Emotet 為例)
身為資安分析師，拿到報告後不能只是看看，你要執行以下 SOP：

1.理解背景： 這份 Emotet 報告是在講什麼？攻擊對象包含我們公司嗎？

2.分類指標 (IOCs)： 把報告裡的 IP、檔案 Hash、惡意信件標題整理出來。

3.理解攻擊生命週期： 搭配 MITRE ATT&CK 框架。它是怎麼進來的？（魚叉式釣魚）進來後怎麼躲？（PowerShell）

4.驗證情資： 把報告裡的 IP 丟到 VirusTotal 查查，看是不是真的還有害。

5.導入防禦： 把驗證過的黑名單丟進防火牆攔截。

6.主動獵捕： 既然知道了 Emotet 的特徵，立刻去掃描全公司的電腦，看有沒有人已經中招但沒被發現。

7.持續監控與回饋： 如果你發現了報告沒寫到的新特徵，記得回報給社群。
