# Threat Hunting Fundamentals
## 一、 核心觀念：什麼是威脅獵捕 (Threat Hunting)？
傳統資安是「等警報響了才處理」，但威脅獵捕認為警報可能會失效。
- 定義： 是一種主動性、由人主導、且通常是**基於假設（Hypothesis-driven）**的行為。透過分析網路數據，找出那些躲過自動化設備（如防火牆、防毒軟體）的潛伏威脅。
- 關鍵目標： 降低潛伏時間 (Dwell Time)。目前的攻擊者平均會在企業內躲藏數週甚至數月，獵捕的目標是在他們發動大規模破壞前，在「網路殺傷鏈 (Cyber Kill Chain)」的早期就揪出他們。
- 與事件處理 (IR) 的差別：
  - 威脅獵捕： 主動、前瞻性。在還沒確認有攻擊時，就假設「我已經被入侵了」而去尋找證據。
  - 事件處理： 被動、反應性。已經確認發生事故（有證據了），才去調查、圍堵與復原。
 
## 二、 什麼時候該進行威脅獵捕？ (When to Hunt)
1.得知新威脅或漏洞： 當新聞報導某個你公司有在用的軟體出現「零日漏洞 (0-day)」時。

2.出現新的攻擊指標 (IoC)： 情資顯示某個常攻擊同業的駭客組織，最近換了新的工具或 IP 位址。

3.多個異常跡象同時發生： 單一異常可能是系統錯誤，但如果流量異常 + 登入失敗次數增加，這就是獵捕信號。

4.在事件處理 (IR) 期間： 當你在修補 A 電腦的病毒時，獵捕人員要同步清查網內其他電腦是否也被滲透，防止死灰復燃。

## 三、 獵捕團隊的組成成員
一個成熟的獵捕團隊不只有獵人，還需要跨領域協作：
- Threat Hunter (獵人)： 核心角色，負責分析數據、建立假設，主動搜尋入侵指標（Indicators of Comfect，IoC）。
- Threat Intelligence Analyst (情資分析師)： 提供外部情報，包括開源情報、暗網情報、產業報告及威脅資訊流，告訴獵人當前威脅格局並預測未來趨勢。
- Forensics Experts (鑑識專家)： 精通數位鑑識與事件應變（DFIR），深入分析惡意軟體、逆向工程攻擊及受感染的系統殘骸。
- Data Analysts/Scientists (數據科學家)： 處理巨量 Log，利用 AI 或統計學找出異常模式。
- Security Engineers (資安工程師)： 負責組織安全基礎設施的整體設計，確保獵人有足夠的工具（如 SIEM, EDR）可以使用。
- Network Security Analyst (網路安全分析師)：專精於網路行為與流量模式，了解網路活動的正常起伏。
- SOC Manager：安全作業中心（SOC）經理負責監督威脅獵捕團隊的運作

## 四、關鍵術語
- Dwell Time (潛伏時間)： 駭客入侵到被發現之間的時間。越短越好。
- TTPs (戰術、技術、程序)： 駭客的「作案手法」。獵捕不只是找 IP (IoC)，更要找 TTPs。
- Baseline (基準線)： 你必須先知道「正常的網路長怎樣」，才能分辨出什麼是「異常」。
- Crown Jewels (核心資產)： 公司最值錢的資料（如客戶個資、研發原始碼）。獵捕應優先保護這裡。
