# Threat Hunting Glossary
## 1.誰是威脅？(Adversary, APT, Threat)
這部分在定義你的對手。
- 對手 (Adversary)： 指的是有目標、有動機想要入侵你的人。分為四類：
  - 網路罪犯 (Cyber criminals)： 為了錢。
  - 內部威脅 (Insider threats)： 公司內部的叛徒。
  - 駭客行動主義者 (Hacktivists)： 為了政治或社會議題（如匿名者組織）。
  - 國家級駭客 (State-sponsored)： 為了國家利益與間諜活動。
- 進階持續性威脅 (APT)： 這不代表他們的技術一定「超先進」，而是指他們有錢、有人、有時間跟妳耗。他們非常有耐性，會長期待在你的網路裡直到達成目標。
- 威脅 (Threat) 的組成公式：
    威脅 = 意圖 (Intent) + 能力 (Capability) + 機會 (Opportunity)
  - 他想不想弄你？（意圖）
  - 他有沒有工具跟技術？（能力）
  - 你的防禦有沒有漏洞讓他鑽？（機會）
    
## 2. 什麼是 TTPs？(最核心的手法概念)
這是資安人員每天都會掛在嘴邊的詞，它是駭客的「行為指紋」：
- Tactics (戰術)： **「為什麼」** 要做這件事？（例如：為了「獲取初始存取權」）。
- Techniques (技術)： **「如何」** 實現戰術？（例如：透過「魚叉式釣魚郵件」）。
- Procedures (程序)： 具體的 **「步驟」**。（例如：先註冊域名 -> 寫惡意巨集 -> 發送給 HR 部門）。

## 3. 痛苦之金字塔 (Pyramid of Pain)
這是由 David Bianco 提出的觀念，說明**「偵測哪些指標會讓駭客最痛苦」**。越往頂端，駭客越難更改手法。
|層級|指標內容|對駭客的難度|說明|
|---|---|---|---|
|頂端|TTPs|極度痛苦|這是駭客的習慣。要他改掉攻擊習慣，等於要一個人改掉慣用手一樣難。|
|高層|工具(Tools)|挑戰|駭客被發現用某款軟體後，他得重新開發或學習新工具。|
|中層|主機/網路痕跡|惱人|像是在 Registry 留下的關鍵字。改這些會影響他的穩定性。|
|低層|網域(Domains)|簡單|駭客換個網址只要幾分鐘。|
|底層|IP位址|微不足道|駭客隨時可以換 IP，偵測這個效果最差。|
|底層|Hash|值微不足道|檔案改一個字元 Hash 就變了，這最好改。|

## 4. 分析模型：鑽石模型 (Diamond Model)
這是一個科學框架，幫你把一次入侵事件的「四個頂點」連起來，看清全貌：
1.對手 (Adversary)： 誰幹的？（動機、身分）。

2.能力 (Capability)： 用什麼武器？（惡意程式、漏洞利用程式）。

3.基礎設施 (Infrastructure)： 透過哪裡攻擊？（IP、C2 伺服器、殭屍網路）。

4.受害者 (Victim)： 誰被打了？（你的公司、特定的伺服器）。

與 Cyber Kill Chain 的差別：
- Kill Chain 關注的是攻擊的「時間先後步驟」（先偵查、再入侵、最後破壞）。
- Diamond Model 關注的是攻擊的「組成元素與關係」。
